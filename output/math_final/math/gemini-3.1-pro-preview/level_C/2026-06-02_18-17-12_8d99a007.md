## Explanation

$z = \cos\frac{2\pi}{7} + i\sin\frac{2\pi}{7}$ болғандықтан, Муавр формуласы бойынша $z^7 = 1$ және $z \neq 1$.
Біз $1 + z + z^2 + z^3 + z^4 + z^5 + z^6 = 0$ теңдігін білеміз.
Ізделінді өрнекті $S = z + z^2 + z^4$ деп белгілейік.
Онда оның түйіндесі: $\bar{S} = \bar{z} + \bar{z}^2 + \bar{z}^4$.
$\bar{z} = \frac{1}{z} = z^6$ болғандықтан, $\bar{S} = z^6 + z^5 + z^3$.
Комплекс сандардың қосындысы мен көбейтіндісін табайық:
1) $S + \bar{S} = (z + z^2 + z^4) + (z^6 + z^5 + z^3) = z + z^2 + z^3 + z^4 + z^5 + z^6$.
Жоғарыдағы теңдікті қолдансақ, $S + \bar{S} = -1$.
2) $S \cdot \bar{S} = (z + z^2 + z^4)(z^3 + z^5 + z^6) = z^4 + z^6 + z^7 + z^5 + z^7 + z^8 + z^7 + z^9 + z^{10}$.
$z^7 = 1$ екенін ескерсек: $z^8 = z$, $z^9 = z^2$, $z^{10} = z^3$.
$S \cdot \bar{S} = z^4 + z^6 + 1 + z^5 + 1 + z + 1 + z^2 + z^3 = 3 + (z + z^2 + z^3 + z^4 + z^5 + z^6) = 3 - 1 = 2$.
Демек, $S$ және $\bar{S}$ сандары Виет теоремасына сәйкес келесі квадрат теңдеудің түбірлері болады:
$x^2 - (S + \bar{S})x + S \cdot \bar{S} = 0 \implies x^2 + x + 2 = 0$.
Бұл теңдеудің түбірлері: $x = \frac{-1 \pm i\sqrt{7}}{2}$.
Енді $S$-тің жорамал бөлігінің таңбасын анықтайық:
$\text{Im}(S) = \sin\frac{2\pi}{7} + \sin\frac{4\pi}{7} + \sin\frac{8\pi}{7} = \sin\frac{2\pi}{7} + \sin\frac{4\pi}{7} - \sin\frac{\pi}{7}$.
$\sin\frac{2\pi}{7} > \sin\frac{\pi}{7}$ және $\sin\frac{4\pi}{7} > 0$ болғандықтан, $\text{Im}(S) > 0$.
Олай болса, ізделінді мән: $S = \frac{-1 + i\sqrt{7}}{2}$.
