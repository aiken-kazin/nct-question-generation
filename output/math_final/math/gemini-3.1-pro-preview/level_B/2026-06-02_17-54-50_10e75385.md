## Question

Шеңберге сырттай сызылған теңбүйірлі трапецияның табандары $2$ см және $18$ см. Осы шеңбердің радиусын табыңыз.

## Options

- **A)** $5$ см
- **B)** $6$ см
- **C)** $3$ см ✓
- **D)** $4$ см

## Correct Answer

**C**

## Explanation

1. Трапеция шеңберге сырттай сызылғандықтан, оның қарама-қарсы қабырғаларының қосындысы тең болады: $a + b = c + c \Rightarrow a + b = 2c$, мұндағы $a$ және $b$ — табандары, $c$ — бүйір қабырғасы.
2. $2 + 18 = 2c \Rightarrow 2c = 20 \Rightarrow c = 10$ см.
3. Теңбүйірлі трапецияның биіктігін $h$ деп белгілейік. Жоғарғы табанының төбесінен түсірілген биіктік төменгі табанда тікбұрышты үшбұрыш құрайды. Бұл үшбұрыштың төменгі катеті табандарының айырмасының жартысына тең: $x = \frac{18 - 2}{2} = 8$ см.
4. Пифагор теоремасы бойынша биіктікті табамыз: $h = \sqrt{c^2 - x^2} = \sqrt{10^2 - 8^2} = \sqrt{100 - 64} = \sqrt{36} = 6$ см.
5. Шеңбер трапецияға іштей сызылғандықтан, трапецияның биіктігі шеңбердің диаметріне тең болады ($h = d = 2r$). Ендеше, ізделінді радиус $r = \frac{h}{2} = \frac{6}{2} = 3$ см.
