## Explanation

Берілген теңсіздік: $\frac{x^2 - x - 6}{x + 1} \leq 0$.

**1-қадам: Алымды жіктейміз.**
$x^2 - x - 6 = (x - 3)(x + 2)$.

Сонда теңсіздік мынадай түрге келеді:
$$\frac{(x-3)(x+2)}{x+1} \leq 0$$

**2-қадам: Нөлдерді табамыз.**
Алым нөлге тең болғанда: $x = 3$ немесе $x = -2$.
Бөлім нөлге тең болғанда: $x = -1$ (бұл нүкте ОА-ға кірмейді).

**3-қадам: Аралық әдісін қолданамыз.**
Сан осінде нүктелерді орналастырамыз: $-2, -1, 3$.

Тексеру аралықтары:
- $x < -2$, мысалы $x = -3$: $\frac{(-6)(-1)}{(-2)} = \frac{6}{-2} = -3 < 0$ ✓
- $-2 < x < -1$, мысалы $x = -1{,}5$: $\frac{(-4{,}5)(-0{,}5)}{(-0{,}5)} = \frac{2{,}25}{-0{,}5} < 0$ — жоқ, $\frac{(-4{,}5)(0{,}5)}{(-0{,}5)}$... қайта есептейік: $x=-1{,}5$: $(x-3)=-4{,}5$, $(x+2)=0{,}5$, $(x+1)=-0{,}5$; көбейтінді: $\frac{(-4{,}5)(0{,}5)}{-0{,}5} = \frac{-2{,}25}{-0{,}5} = 4{,}5 > 0$ ✗
- $-1 < x < 3$, мысалы $x = 0$: $\frac{(-3)(2)}{1} = -6 < 0$ ✓
- $x > 3$, мысалы $x = 4$: $\frac{(1)(6)}{5} = 1{,}2 > 0$ ✗

**4-қадам: Теңдік жағдайын тексереміз.**
$x = -2$: $\frac{0}{-1} = 0 \leq 0$ ✓ (кіреді)
$x = -1$: бөлім нөл, кірмейді.
$x = 3$: $\frac{0}{4} = 0 \leq 0$ ✓ (кіреді)

**Жауап:** $x \in (-\infty; -2] \cup (-1; 3]$.
