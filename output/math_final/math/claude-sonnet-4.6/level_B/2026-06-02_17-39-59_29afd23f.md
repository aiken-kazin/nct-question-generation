Егер $\sin x + \cos x = \frac{\sqrt{6}}{2}$ болса, $\sin x \cdot \cos x$ мәнін табыңыз.

## Options

## Correct Answer

**A**

## Explanation

Берілген шарт: $\sin x + \cos x = \frac{\sqrt{6}}{2}$.

Екі жағын да квадратқа көтереміз:
$$\left(\sin x + \cos x\right)^2 = \left(\frac{\sqrt{6}}{2}\right)^2$$
$$\sin^2 x + 2\sin x \cos x + \cos^2 x = \frac{6}{4}$$

Пифагор тепе-теңдігіне сәйкес $\sin^2 x + \cos^2 x = 1$ болғандықтан:
$$1 + 2\sin x \cos x = \frac{6}{4} = \frac{3}{2}$$
$$2\sin x \cos x = \frac{3}{2} - 1 = \frac{1}{2}$$
$$\sin x \cos x = \frac{1}{4}$$

Демек, жауабы $\frac{1}{4}$.
