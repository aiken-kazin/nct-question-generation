## Question

Келесі квадраттық теңдеудің түбірлерін табыңыз: $x^2 - 5x + 6 = 0$.

## Options

- **A)** $x = 2 \text{ және } x = 3$ ✓
- **B)** $x = -2 \text{ және } x = -3$
- **C)** $x = 1 \text{ және } x = 6$
- **D)** $x = -1 \text{ және } x = -6$

## Correct Answer

**A**

## Explanation

Берілген теңдеу $x^2 - 5x + 6 = 0$. Бұл квадраттық теңдеуді шешу үшін оны көбейткіштерге жіктейміз: 
$$x^2 - 5x + 6 = (x - 2)(x - 3) = 0.$$ 
Енді әрбір жақшаны $0$-ге теңестіреміз: 
$x - 2 = 0$ немесе $x - 3 = 0$. 
Сонымен, $x = 2$ және $x = 3$. Демек, дұрыс жауап: $x = 2 \text{ және } x = 3$.
