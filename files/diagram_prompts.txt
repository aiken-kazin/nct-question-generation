================================================================================
IMAGE-GENERATION PROMPTS — NTC QUESTION-GENERATION PIPELINE DIAGRAMS
================================================================================

Use these with DALL·E 3, GPT-Image, Midjourney, or any text-to-image model that
handles diagram text well. For Midjourney add `--ar 16:9 --style raw --v 6`. For
DALL·E use the prompt as-is.

Style guidance applied to every prompt:
- Clean academic-paper figure style (publishable in IEEE/Springer/Elsevier).
- Flat 2D vector look, no 3D, no shadows, no gradients, no glow.
- White or off-white background (#FFFFFF or #FAFAFA).
- Monospace or clean sans-serif labels (Inter / Helvetica / IBM Plex).
- Boxes: rounded corners, 2px borders. Decisions: diamond shapes.
- Color palette: deep blue (#1F4E79) for agents, soft green (#5A8F69) for
  artifacts/outputs, amber (#D9A441) for retry/feedback, neutral gray (#4B4B4B)
  for arrows, light fills (10–15% opacity tints of the same hues).
- All text in English (research paper figures).
- No emojis. No decorative icons. No watermark.

NOTE FOR ALL PROMPTS: AI image generators frequently misspell or rearrange text
in diagrams. For a publishable final figure, prefer rebuilding the diagram in
Mermaid / draw.io / TikZ once you've chosen a layout. These prompts are useful
for early concept rendering and slide decks.

================================================================================
USAGE TIPS
================================================================================

1. For each prompt, generate 3–4 variants and pick the cleanest layout.
2. AI image generators routinely misspell technical terms ("Kazakh",
   "Krippendorff", "OpenRouter"). Always proofread the output.
3. For the final paper submission, rebuild the chosen layout in:
     • Mermaid (good for Prompts 1, 3, 6) — copy-pasteable into LaTeX/Markdown
     • draw.io / diagrams.net (good for Prompts 2, 4, 5)
     • TikZ (best journal-ready quality, slowest to author)
4. Keep the visual style consistent across all figures in the paper —
   one color palette, one font family, one corner-radius.
5. If submitting to JAIT, check their figure-resolution requirements
   (typically 300 DPI minimum for raster, vector preferred).
